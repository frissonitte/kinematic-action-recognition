# License & Asset Availability

This repository is strictly for codebase version control and academic demonstration. Due to the restricted nature of the raw dataset, a Code-Data Separation approach has been applied:

-Source Code: The Python scripts and notebooks within this repository are open-sourced under the MIT License.

-Dataset: The raw 10GB sensor dataset is restricted/proprietary and is not included in this repository.

-Trained Models: The trained machine learning models (e.g., rf_supervised.pkl, kmeans_model.pkl) and the extracted feature matrix are hosted securely and evaluated on Kaggle to ensure reproducibility. You can view the execution and model performance here: [Link to project's Kaggle Notebook](https://www.kaggle.com/code/frissonitte/notebook4f9a6e9e9b/)
