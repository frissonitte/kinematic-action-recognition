## License & Asset Availability

This repository is strictly for codebase version control and academic demonstration. Due to the restricted nature of the raw dataset, a **Code-Data Separation** approach has been applied:

-**Source Code:** The Python scripts and notebooks within this repository are open-sourced under the MIT License.

-**Dataset:** The raw 10GB sensor dataset is restricted/proprietary and is **not** included in this public repository.

-**Trained Models & Reproducibility:** The trained machine learning models (e.g., `rf_supervised.pkl`, `kmeans_model.pkl`) and the extracted feature matrices are hosted securely and evaluated privately on Kaggle to ensure full reproducibility without violating data sovereignty.
